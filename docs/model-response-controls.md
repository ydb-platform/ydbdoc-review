# F04: управление ответом модели

Проверка официальной документации: 19 сентября 2026. Платных вызовов модели не было.

## Установлено

Default проекта использует Yandex AI Studio Chat Completions:
`https://ai.api.cloud.yandex.net/v1/chat/completions`, модель
`gpt://<folder>/deepseek-v4-flash` (DeepSeek V4 Flash), согласованная пользователем
замена V3.2. Единственная альтернатива перевода/исправления — YandexGPT Pro 5. Перевод и исправление используют один выбор модели.

[Официальная схема Chat Completions](https://aistudio.yandex.ru/ru/docs/ai-studio/api/Chat-Completions/createChatCompletion)
описывает `reasoning_effort` и `max_tokens`. Последний устарел в пользу
`max_completion_tokens`, учитывающего и видимый ответ, и reasoning.
Мы сохраняем документированный `max_tokens`, чтобы не предполагать поддержку
нового поля конкретным развёртыванием. `RequestBudget.max_output_tokens` передаётся
как `chat(max_tokens=...)` без скрытого увеличения. Текущее значение — 8000,
контекст — 32768; это настройки проекта, не утверждение о предельных возможностях
моделей. Менять резерв необходимо совместно с расчётом вместимости F05.

[Руководство YC по рассуждениям](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/chain-of-thought)
указывает, что возможность отключения зависит от конкретной модели. Общая API-схема
не доказывает поддержку `none` моделью `deepseek-v4-flash`. Параметры другого сервиса
`api.deepseek.com` также не доказывают совместимость Yandex Cloud.

[Release notes YC, 28 мая 2026](https://aistudio.yandex.ru/ru/docs/ai-studio/release-notes/)
сообщают о замене DeepSeek V3.2 моделью V4 Flash и прекращении действия старого URI
после 28 июня 2026. Поэтому default переведён на новый документированный URI; старый URI не является
доказанным алиасом V4. Явные операторские overrides сохраняются.

## Реализованный интерфейс и ограничения

Технический JSON принимает необязательный `reasoning_effort` у каждого endpoint
Yandex Cloud; поле напрямую передаётся в HTTP payload и сохраняется с запросом.
Это явная операторская настройка: сначала подтвердить поддержку точным
развёртыванием. Для альтернативы поле задаётся отдельно, автоматически не копируется.
Default не включает недоказанное значение reasoning. Ни `thinking`, ни
`chat_template_kwargs` другого провайдера в YC payload не добавляются.

`ModelError.kind` различает `empty`, `length`, `invalid_format`, `transport`.
Reasoning-only с `length` диагностируется как исчерпание выходного бюджета; reasoning
не подставляется вместо перевода. Непустой частичный ответ с `length` возвращается
как `ModelResult`, `response_status == 'length'`, чтобы сохранить полезный перевод.
Потребитель обязан учитывать `finish_reason` и оставить часть незавершённой.
В attempt остаётся диагноз исчерпания лимита. Все эти ответы сохраняют полную
попытку и usage один раз; fallback по качеству не запускается.

Проверки HTTP — имитации через `requests.Session.send`. Они подтверждают payload,
диагностику, сохранение частичного текста, число попыток и расчёт стоимости, но не
живую совместимость. Проверка web-страниц была живой и бесплатной.

## Параметры миграции V4 Flash

[Каталог YC](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models)
подтверждает URI `deepseek-v4-flash`, OpenAI-совместимые API и контекст 1 048 576
токенов. Общий бюджет проекта остаётся 32768/8000: он должен учитывать также
32k-контекст альтернативы и критика. Миллионный контекст основной модели не
разрешает отправлять такой запрос альтернативе. Отдельный максимальный выход
V4 Flash в просмотренных YC каталоге, лимитах и API-схеме не установлен; 8000 —
ограничение проекта, его пригодность для живого перевода не подтверждена.

[Синхронные тарифы YC](https://aistudio.yandex.ru/ru/docs/ai-studio/pricing)
дают на миллион токенов V4 Flash: вход 300 ₽, кешированный вход 75 ₽, выход 500 ₽,
с НДС. Эти значения записаны в default вместо тарифа снятой V3.2. Тарифы
альтернативы и критика сохранены. Это ставки расчёта по usage, не обещание цены
документа; reasoning-only также учитывается по usage.

**F04 закрыт частично:** согласованная замена модели и её тариф реализованы,
существующая диагностика ответов сохранена. Не установлено, какой параметр YC
отключает reasoning у V4 Flash. Остаются подтверждение этого режима точным YC
endpoint и независимая проверка токенизации F05. До их завершения миграция
конфигурации не означает эксплуатационную готовность. Платного smoke test не было.
