# Memory Bank — согласованные решения владельца продукта

Дата: 2026-09-14. Источник: явные ответы пользователя в текущем MARS-чате.
Канон: [REQUIREMENTS_RU.md, §0](../../REQUIREMENTS_RU.md).

## D-001 — ветка и PR обязательны, затем критик

Пользователь: «ветка должна быть», «PR должен быть всегда».
Перевод сохраняется в ветке и PR до первого critic. Затем: critic → первое
исправление при замечаниях → critic → второе исправление при замечаниях →
critic → итоговый вердикт в PR. При раннем чистом результате цикл завершается.
Ошибки QA, отказ критика и оставшиеся замечания не отменяют PR; неполная QA
отмечается явно. Не более двух попыток исправления.

Это отменяет прежнюю рекомендацию аудита withholding по качеству и прежние
publication veto в R-GL-12/13, §6.253 и связанных исторических записях.
Проверки содержимого нужны, но определяют вердикт, а не наличие PR.
Draft/обычный PR этим решением отдельно не выбирался.

## D-002 — новая метка запускает перевод с нуля

Пользователь: «новая метка doc_translate должна удалить текущую ветку и заново запустить перевод».
Удаляется текущая ветка перевода этого исходного PR, затем создаётся новая ветка
и выполняется полный перевод с циклом D-001. Неизменённый исходный SHA не
является причиной пропуска. Старый перевод, Analyze no-op и checkpoint не
заменяют новый полный запуск. Исходная ветка автора не удаляется.
