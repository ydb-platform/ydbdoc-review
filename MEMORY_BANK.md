# Memory Bank archive

Memory Bank сохранён только как историческая и архитектурная справка. Он не является источником требований и не может добавлять или изменять поведение `doc_translate`, `doc_continue` и `doc_verify`.

Действующий контракт полностью определён в [`REQUIREMENTS_RU.md`](REQUIREMENTS_RU.md). Краткая самостоятельная копия для инструментов находится в [`.cursor/knowledge-bank.md`](.cursor/knowledge-bank.md).

Файлы в [`docs/memory-bank/`](docs/memory-bank/) являются ненормативным архивом прежних решений. Их алгоритмы и статусы нельзя использовать как требования к реализации.
