# Банк знаний

Действующий контракт: [REQUIREMENTS_RU.md](REQUIREMENTS_RU.md). Этот файл — краткое описание согласованных решений, не самостоятельный источник требований.

## Перевод документа

- Для каждого Markdown/YFM-файла строится простой упорядоченный план: диапазон строк, тип узла и признак перевода. Это не общий граф репозитория и не причина обходить посторонние файлы.
- Модель получает цельный файл или цельный чанк, включая настоящий код, конфиги и ссылки. Поэтому она видит контекст и не должна возвращать сотни плейсхолдеров.
- Из ответа берутся только значения переводимых узлов, включая комментарии по следующему пункту. Неизменяемые части кода, конфиги, URL, include, TOC, YFM, Mermaid, идентификаторы и техническая разметка восстанавливаются из исходных байтов. Исключение для URL: локальная замена при установленном соответствии и проверенной цели по §5 требований; исходный и новый адрес с основанием замены сохраняются.
- В fenced Python/Bash/YAML переводятся только уверенно найденные `#`-комментарии; в C++/Java/JavaScript — `//` и `/* ... */`. Если комментарий или язык не распознаны уверенно, весь code-блок остаётся исходным.
- При невозможности сопоставить ответ с планом затронутый чанк оставляется исходным. Итог публикуется RED для ручной правки, если он читаем и содержит другие изменения. Модельный fallback по качеству не запускается.
- Большие файлы делятся между целыми разделами или блоками, никогда внутри предложения, таблицы, include или code-блока.

## Границы и диагностика

- Проверки касаются только файлов плана и явных зависимостей, не всего дерева документации.
- Полные запросы и ответы хранятся в YDB. Диагностические файлы, отдельные артефакты и полные логи в GitHub или репозиторий не публикуются.
- Все модельные обращения используют отключённые рассуждения. Ответ с `finish_reason=length` непригоден.

## Тесты

- Нужен небольшой быстрый набор, примерно 15–20 фикстур: обычный Markdown, ссылки/таблицы/include/YFM/TOC/Mermaid, известные code-комментарии, сборка исходных байтов, chunking и испорченные ответы.
- Тесты локальные, без сети и модели. Устаревшие тесты отменённого сегментного JSON-контракта удаляются, а не сохраняются ради зелёного CI.
